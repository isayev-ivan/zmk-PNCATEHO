# Project Rules

- Перед написанием нового кода всегда проверь, нет ли уже эквивалентной реализации в проекте.
- Приоритет: переиспользовать существующий код вместо создания нового.
- Запрещено создавать дубли функций, макросов, behaviors, слоев и конфиг-структур без явной причины.
- Если найдено похожее решение, сначала предложи рефакторинг/расширение существующего.
