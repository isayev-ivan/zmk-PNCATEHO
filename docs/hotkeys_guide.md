# Как использовать горячие клавиши (Hotkeys) в PNCATEHO

В этой клавиатуре модификаторы (**Cmd**, **Ctrl**, **Alt**, **Shift**) работают в режиме **Sticky Keys** ("Липкие клавиши"). Это значит, что их не нужно удерживать одновременно с буквой. Вы нажимаете модификатор, отпускаете его, а затем нажимаете нужную букву.

## Где находятся модификаторы?

В текущем конфиге модификаторы вызываются через `TCOMBO_NO_BASE` при добавлении **Согнутого большого пальца (Curved Thumb: `LIT`/`RIT`)**.

| Клавиша-основа | Какой палец нажимает | Модификатор (при добавлении Curved Thumb) |
| :--- | :--- | :--- |
| **H** | Мизинец (Bottom Pinky) | **Cmd** (GUI) |
| **C** | Безымянный (Bottom Ring) | **Opt** (Alt) |
| **N** | Средний (Bottom Middle) | **Ctrl** |
| **Y** | Указательный (Bottom Index) | **Shift** |

*(На левой половине это нижний ряд: H-C-N-Y слева направо. На правой половине зеркально: Y-N-C-H)*

---

## Примеры использования

### 1. Копировать (Cmd + C)
1. **Активируйте Cmd**: Нажмите аккорд для **H** (нижний мизинец) + **согнутый большой палец**. Отпустите.
   *(Теперь клавиатура "помнит", что Cmd нажат)*
2. **Нажмите C**: Нажмите обычный аккорд для **C** (нижний безымянный).

### 2. Вставить (Cmd + V)
1. **Активируйте Cmd**: Нажмите аккорд для **H** + **согнутый большой палец**. Отпустите.
2. **Нажмите V**: Нажмите обычный аккорд для **V** (нижний средний + указательный).

### 3. Вырезать (Cmd + X)
1. **Активируйте Cmd**: Нажмите аккорд для **H** + **согнутый большой палец**. Отпустите.
2. **Нажмите X**: Нажмите обычный аккорд для **X** (нижний мизинец + указательный).

### 4. Сложное сочетание: Opt + Shift + V
Здесь можно действовать последовательно, "наслаивая" модификаторы.

1. **Активируйте Opt**: Нажмите аккорд **C** + **согнутый большой палец**. Отпустите.
2. **Активируйте Shift**: Нажмите аккорд **Y** + **согнутый большой палец**. Отпустите.
3. **Нажмите V**: Нажмите обычный аккорд **V**.

Дополнение: для большинства `TCOMBO`-аккордов добавление curved-thumb действительно дает вариант `Shift+буква` (`CURVED_BINDINGS`), но для `H/C/N/Y` в вашем конфиге curved уже занят под sticky-модификаторы.

## Таблица-шпаргалка по аккордам модификаторов

Ниже приведены точные комбинации пальцев для вызова модификаторов (для левой руки).
`BLP` = Bottom Left Pinky (Левый Нижний Мизинец) и т.д.
`LIT` = Left Inner/Curved Thumb (Левый Согнутый Большой)

| Модификатор | Комбинация (Левая рука) | Комбинация (Правая рука) |
| :--- | :--- | :--- |
| **Cmd** (GUI) | `BLP` + `LIT` | `BRP` + `RIT` |
| **Opt** (Alt) | `BLR` + `LIT` | `BRR` + `RIT` |
| **Ctrl** | `BLM` + `LIT` | `BRM` + `RIT` |
| **Shift** | `BLI` + `LIT` | `BRI` + `RIT` |
