# Справочник по сокращениям позиций клавиш

Этот файл расшифровывает сокращения вида `TLP`, `BLR`, `LOT` и т.д. из прошивки клавиатуры.

Источник сокращений: [config/boards/shields/PNCATEHO/PNCATEHO.keymap](/Users/iv_/WebstormProjects/zmk-PNCATEHO/config/boards/shields/PNCATEHO/PNCATEHO.keymap#L17)

## Общий принцип

Сокращение обычно состоит из 3 букв:

- `T` = `Top` = верхний ряд
- `B` = `Bottom` = нижний ряд
- `L` = `Left` = левая половина
- `R` = `Right` = правая половина
- `P` = `Pinky` = мизинец
- `R` = `Ring` = безымянный палец
- `M` = `Middle` = средний палец
- `I` = `Index` = указательный палец

Для больших пальцев используются отдельные сокращения:

- `O` = `Outer` = внешний
- `I` = `Inner` = внутренний
- `THUMB` = большой палец

## Коротко про LIT и LOT

- `LIT` — это левая thumb-клавиша, которая расположена ближе к центру клавиатуры (внутрь ладони).
- `LOT` — это левая thumb-клавиша, которая расположена ближе к внешнему краю левой половинки.

## Как читать запись аккорда

Пример: `TLP + BLR`

- `TLP` = верхняя левая клавиша под мизинцем
- `BLR` = нижняя левая клавиша под безымянным пальцем

Значит нужно нажать эти две клавиши одновременно.

Пример: `TLR + BLM + LOT`

- `TLR` = верхняя левая под безымянным
- `BLM` = нижняя левая под средним
- `LOT` = внешний большой палец слева

Значит это аккорд из двух обычных клавиш и внешнего левого большого пальца.
