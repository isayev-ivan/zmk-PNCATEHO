# Справочник по сокращениям позиций клавиш

Этот файл расшифровывает сокращения вида `TLP`, `BLR`, `LOT` и т.д. из прошивки клавиатуры.

Источник сокращений: [config/boards/shields/PNCATEHO/PNCATEHO.keymap](/Users/iv_/WebstormProjects/zmk-PNCATEHO/config/boards/shields/PNCATEHO/PNCATEHO.keymap#L17)

## Общий принцип

Сокращение обычно состоит из 3 букв:

- `T` = `Top` = верхний ряд
- `B` = `Bottom` = нижний ряд
- `L` = `Left` = левая половина
- `R` = `Right` = правая половина
- `P` = `Pinky` = мизинец
- `R` = `Ring` = безымянный палец
- `M` = `Middle` = средний палец
- `I` = `Index` = указательный палец

Для больших пальцев используются отдельные сокращения:

- `O` = `Outer` (теперь Splayed) = разогнутый большой палец (к указательному)
- `I` = `Inner` (теперь Curved) = согнутый большой палец (к мизинцу)
- `THUMB` = большой палец

## Большие пальцы (Thumb Keys)

Для исключения путаницы с "внешним" и "внутренним", сейчас используются термины **Curved** (согнутый) и **Splayed** (разогнутый). Аббревиатуры `LIT`/`LOT`/`RIT`/`ROT` сохранены для обратной совместимости в коде:

*Для левой руки:*
- `LIT` (Left Inner/Curved Thumb) — согнутый палец (ближе к мизинцу, левая кнопка)
- `LOT` (Left Outer/Splayed Thumb) — разогнутый/вытянутый палец (ближе к указательному, правая кнопка)

*Для правой руки (зеркально):*
- `ROT` (Right Outer/Splayed Thumb) — разогнутый/вытянутый палец (ближе к указательному, левая кнопка)
- `RIT` (Right Inner/Curved Thumb) — согнутый палец (ближе к мизинцу, правая кнопка)

## Как читать запись аккорда

Пример: `TLP + BLR`

- `TLP` = верхняя левая клавиша под мизинцем
- `BLR` = нижняя левая клавиша под безымянным пальцем

Значит нужно нажать эти две клавиши одновременно.

Пример: `TLR + BLM + LOT`

- `TLR` = верхняя левая под безымянным
- `BLM` = нижняя левая под средним
- `LOT` = внешний большой палец слева

Значит это аккорд из двух обычных клавиш и внешнего левого большого пальца.
