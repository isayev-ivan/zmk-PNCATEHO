# Инструкция по сборке и прошивке клавиатуры PNCATEHO

## 1. Сборка прошивки (Build)

В этом проекте используется **GitHub Actions** для автоматической сборки прошивки ZMK. Вам не нужно устанавливать среду разработки локально.

### Шаги для сборки:

1.  **Внесите изменения** в файлы конфигурации (например, в `config/boards/shields/PNCATEHO/PNCATEHO.keymap` или `config/boards/shields/PNCATEHO/chords.dtsi`).
2.  **Закоммитьте и отправьте (push)** изменения в ваш репозиторий на GitHub.
    ```bash
    git add .
    git commit -m "Описание изменений"
    git push origin main
    ```
3.  Перейдите на страницу вашего репозитория на **GitHub**.
4.  Откройте вкладку **Actions** (вверху страницы).
5.  Вы увидите запущенный процесс сборки (workflow run), обычно с названием вашего коммита.
6.  Дождитесь окончания сборки (зеленая галочка ✅).
7.  Кликните на название успешной сборки.
8.  Внизу страницы, в разделе **Artifacts**, скачайте файл `firmware` (это будет zip-архив).

## 2. Прошивка клавиатуры (Flash)

После скачивания архива `firmware.zip`:

1.  **Распакуйте архив**. Внутри вы найдете файлы с расширением `.uf2`. Обычно их два (для левой и правой половинки), например:
    *   `PNCATEHO_left-nice_nano-zmk.uf2`
    *   `PNCATEHO_right-nice_nano-zmk.uf2`
    *(Названия могут отличаться, но суть одна: left и right)*.

2.  **Подключите левую половинку** клавиатуры к компьютеру через USB.

3.  **Переведите клавиатуру в режим загрузчика (Bootloader)**:
    *   Быстро нажмите кнопку **Reset** на контроллере (или специальную кнопку на клавиатуре) **два раза подряд**.
    *   Клавиатура должна определиться как внешний USB-накопитель с названием типа `NICENANO` или `PNCATEHO`.

4.  **Скопируйте файл прошивки**:
    *   Перетащите файл `..._left-...uf2` на этот USB-накопитель.
    *   Накопитель автоматически отключится, и клавиатура перезагрузится с новой прошивкой.

5.  **Повторите для правой половинки**:
    *   Подключите правую половинку по USB.
    *   Дважды нажмите Reset.
    *   Скопируйте файл `..._right-...uf2` на появившийся диск.

### Важные замечания:

*   Если вы используете клавиатуру в беспроводном режиме (Bluetooth), **левая половинка** является главной (central). Именно она подключается к компьютеру. Правая (peripheral) подключается к левой.
*   Если вы меняли только раскладку (keymap), часто достаточно обновить только левую (главную) половинку. Но для надежности рекомендуется обновлять обе.
*   Если после прошивки половинки не видят друг друга, попробуйте сбросить настройки Bluetooth (обычно для этого есть специальный файл прошивки `settings_reset.uf2` в документации ZMK, но это требуется редко).

## 3. Сброс Bluetooth

В этом проекте сброс Bluetooth предусмотрен прямо в раскладке через behavior `&bt BT_CLR`.

Источник истины:

- `config/boards/shields/PNCATEHO/chords.dtsi`
- комбо `bt`: `TCOMBO(bt, &bt BT_SEL 0, &bt BT_SEL 1, &bt BT_SEL 2, &bt BT_CLR, BLP BLR BLM BLI, BRP BRR BRM BRI)`

Это значит:

- обычный 4-клавишный аккорд `bt` переключает на профиль `BT_SEL 0`;
- `bt + curved-thumb` переключает на профиль `BT_SEL 1`;
- `bt + splayed-thumb` переключает на профиль `BT_SEL 2`;
- `bt + оба thumbs` выполняет `BT_CLR`, то есть очищает Bluetooth-профили клавиатуры.

Практически это выглядит так:

1. Нажмите базовый `bt`-аккорд одной рукой:
   - слева: `BLP + BLR + BLM + BLI`, или
   - справа: `BRP + BRR + BRM + BRI`.
2. Для очистки Bluetooth удерживайте вместе с этим аккордом **оба thumb-клавиши** той же стороны:
   - слева: `LIT + LOT`,
   - справа: `RIT + ROT`.
3. После `BT_CLR` удалите устройство из списка Bluetooth-устройств на Mac.
4. Переведите клавиатуру на нужный BT-профиль (`BT_SEL 0/1/2`) и выполните сопряжение заново.

Когда это нужно делать:

- после изменений, влияющих на HID descriptor, например при включении/изменении pointing/mouse;
- если Mac видит клавиатуру, но ввод работает некорректно;
- если половинки или хост "помнят" старое состояние соединения.

Если обычный `BT_CLR` не помог:

1. Соберите или скачайте `settings_reset.uf2` из экосистемы ZMK.
2. Прошейте `settings_reset` на левую половину.
3. Прошейте `settings_reset` на правую половину.
4. После этого заново прошейте обычные `...left...uf2` и `...right...uf2`.
5. Удалите старое устройство на Mac и спарьте клавиатуру заново.

`settings_reset` нужен редко, но это самый жесткий способ очистить сохраненные настройки на обеих половинах.

## 4. Скрипт `key_debug.py`

В корне репозитория есть вспомогательный скрипт [key_debug.py](file:///Users/iv_/WebstormProjects/zmk-PNCATEHO/key_debug.py). Это не часть прошивки ZMK и не tool для прошивки. Это локальный диагностический скрипт для macOS/Linux/Windows, который слушает нажатия клавиш на хосте и печатает:

- символ клавиши, если это обычная клавиша;
- имя специальной клавиши, если это `Shift`, `Ctrl`, `Cmd` и т.п.;
- virtual key code (`vk`), который видит ОС.

Зачем он нужен:

- быстро проверить, что именно приходит в ОС после нажатия на клавиатуре;
- понять, отправляет ли прошивка ожидаемый keycode;
- сравнить поведение обычных клавиш, модификаторов и спецклавиш;
- диагностировать проблемы "на хосте", когда нужно отделить ошибку прошивки от ошибки приложения/раскладки/macOS.

Что скрипт **не** делает:

- не читает события напрямую из ZMK;
- не помогает прошивать клавиатуру;
- не показывает внутренние слои или behavior'ы прошивки;
- не подходит для диагностики mouse HID (`&mkp`, `&mmv`, `&msc`), потому что он слушает именно клавиатурные события ОС.

Как запустить:

1. Перейдите в корень репозитория.
2. Убедитесь, что установлен Python 3.
3. Установите зависимость:

```bash
pip3 install pynput
```

4. Запустите скрипт:

```bash
python3 key_debug.py
```

5. Нажимайте клавиши и смотрите вывод в терминале.
6. Для выхода нажмите `Esc`.

Особенность macOS:

- терминалу может потребоваться разрешение `Input Monitoring`, иначе `pynput` не сможет получать события клавиатуры.

Когда удобно использовать `key_debug.py`:

- после изменения раскладки, чтобы проверить реальные keycode на хосте;
- при отладке combo/hold-tap/sticky-модификаторов;
- когда кажется, что "клавиатура печатает не то", и нужно увидеть, что именно получает macOS.
