# Режим навигации (Lock Nav)

Этот режим превращает клавиатуру в навигационный блок (стрелки, Home/End, PgUp/PgDn), позволяя перемещаться по тексту и страницам без удержания дополнительных клавиш.

## Как включить / выключить

Для переключения в режим навигации (и обратно) используйте аккорд из 3-х клавиш (аналог ARTSEY `A+T+O`):

*   **Комбинация:** `Top Index` + `Top Ring` + `Bottom Pinky`
*   **Левая рука:** `TLI` (Указательный верх) + `TLR` (Безымянный верх) + `BLP` (Мизинец низ)
*   **Правая рука:** `TRI` (Указательный верх) + `TRR` (Безымянный верх) + `BRP` (Мизинец низ)

## Раскладка в режиме навигации

В этом режиме клавиши работают следующим образом:

### Левая половина

| Ряд | Мизинец (Pinky) | Безымянный (Ring) | Средний (Middle) | Указательный (Index) |
| :--- | :--- | :--- | :--- | :--- |
| **Верхний** | **PgUp** | **Home** | **Up** (Вверх) | **End** |
| **Нижний** | **PgDn** | **Left** (Влево) | **Down** (Вниз) | **Right** (Вправо) |

### Правая половина

| Ряд | Указательный (Index) | Средний (Middle) | Безымянный (Ring) | Мизинец (Pinky) |
| :--- | :--- | :--- | :--- | :--- |
| **Верхний** | **Home** | **Up** (Вверх) | **End** | **PgUp** |
| **Нижний** | **Left** (Влево) | **Down** (Вниз) | **Right** (Вправо) | **PgDn** |

### Большие пальцы (Thumbs)

*   **Внутренний (Inner):** Пробел (Space)
*   **Внешний (Outer):** Backspace (Удаление)
