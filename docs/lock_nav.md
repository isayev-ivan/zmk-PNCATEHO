# Режим навигации (Lock Nav)

Этот режим превращает клавиатуру в навигационный блок (стрелки, Home/End, PgUp/PgDn), позволяя перемещаться по тексту и страницам без удержания дополнительных клавиш.

## Как включить / выключить

Для переключения в режим навигации (и обратно) используйте аккорд из 3-х клавиш (аналог ARTSEY `A+T+O`):

*   **Комбинация:** `Top Middle` + `Bottom Ring` + `Bottom Index`
*   **Левая рука:** `TLM` (Средний верх) + `BLR` (Безымянный низ) + `BLI` (Указательный низ)
*   **Правая рука:** `TRM` (Средний верх) + `BRR` (Безымянный низ) + `BRI` (Указательный низ)

## Раскладка в режиме навигации

В этом режиме клавиши работают следующим образом:

### Левая половина

| Ряд | Мизинец (Pinky) | Безымянный (Ring) | Средний (Middle) | Указательный (Index) |
| :--- | :--- | :--- | :--- | :--- |
| **Верхний** | **PgUp** | **Home** | **Up** (Вверх) | **End** |
| **Нижний** | **PgDn** | **Left** (Влево) | **Down** (Вниз) | **Right** (Вправо) |

### Правая половина

| Ряд | Указательный (Index) | Средний (Middle) | Безымянный (Ring) | Мизинец (Pinky) |
| :--- | :--- | :--- | :--- | :--- |
| **Верхний** | **Home** | **Up** (Вверх) | **End** | **PgUp** |
| **Нижний** | **Left** (Влево) | **Down** (Вниз) | **Right** (Вправо) | **PgDn** |

### Большие пальцы (Thumbs)

*   **Согнутый (Curved, бывш. Inner):** Backspace (Удаление)
*   **Разогнутый (Splayed, бывш. Outer):** Пробел (Space)

## Техническая реализация (ZMK)

`lock_nav` в текущем конфиге создается через:

```c
TCOMBO_ONLY_BASE_LAYERS_IDLE(lock_nav, &tog NAV_L, TLM BLR BLI, TRM BRR BRI, RU_L ENG_L NAV_L MOUSE_L, 150)
```

Это значит:

- only-base комбо (без curved/splayed/both вариантов),
- зеркальная генерация для левой/правой руки,
- активен на слоях `RU_L ENG_L NAV_L MOUSE_L`,
- есть `require-prior-idle-ms = <150>`.

`timeout-ms` берется из `COMBO_TIMEOUT` (сейчас `70`), а не из локального `100`.

### Почему нужен `require-prior-idle-ms`

При использовании 3-клавишных аккордов (`TLM` + `BLR` + `BLI`) часто возникают конфликты с 2-клавишными аккордами, использующими те же клавиши (например, `TLM` + `BLR` для буквы `'`).

Если нажать 3 клавиши недостаточно синхронно, ZMK может распознать первые две как отдельный аккорд и напечатать букву вместо переключения слоя.

**Решение:**
1.  **`key-positions`**: Убедиться, что указаны *реально нажимаемые* клавиши (в нашем случае треугольник `TLM`, `BLR`, `BLI`).
2.  **`timeout-ms = <COMBO_TIMEOUT>`**: используется общий таймаут комбо (в конфиге `70`).
3.  **`require-prior-idle-ms = <150>`**: клавиатура должна быть в покое 150мс перед аккордом.
    
        **Зачем это нужно?**
        Представьте, что вы очень быстро печатаете текст. Ваши пальцы летают по клавиатуре. Вы нажимаете клавиши, которые могут случайно совпасть с вашим аккордом `lock_nav`.
        Без этой настройки ZMK может подумать: "О! Пользователь нажал нужные клавиши! Включаю режим навигации!" — и внезапно посреди набора текста у вас меняется раскладка.

        **Как это работает:**
        1.  Если вы быстро печатаете (интервал между нажатиями меньше 150 мс), ZMK **игнорирует** этот сложный аккорд, даже если вы случайно нажали нужные кнопки.
        2.  Чтобы включить режим навигации намеренно, вы интуитивно делаете микро-паузу (перестаете печатать), а затем спокойно нажимаете аккорд.
