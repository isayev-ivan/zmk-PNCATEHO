# Возможности прошивки ZMK

ZMK (Zephyr Mechanical Keyboard) — это современная прошивка с открытым исходным кодом, ориентированная на беспроводные клавиатуры. Она построена на базе операционной системы реального времени (RTOS) Zephyr.

## Основные возможности

### 1. Беспроводная связь (Bluetooth Low Energy)
*   **Мультипоточность:** Поддержка сопряжения с несколькими устройствами (обычно до 5 профилей) и быстрое переключение между ними.
*   **Надежность:** Оптимизированный стек Bluetooth для стабильного соединения.
*   **Split (Раздельные клавиатуры):** Полная беспроводная связь между половинками клавиатуры (True Wireless Split).

### 2. Энергоэффективность
*   **Глубокий сон (Deep Sleep):** Автоматический переход в режим глубокого энергосбережения при бездействии, что позволяет клавиатуре работать месяцами от одной батарейки (в вашем конфиге это включено: `CONFIG_ZMK_SLEEP=y`).
*   **Управление питанием:** Возможность программно отключать внешнее питание (например, для дисплеев или подсветки) для экономии заряда.

### 3. Декларативная конфигурация
*   Вся настройка производится через файлы описания оборудования (Devicetree, `.dtsi`) и карты клавиш (`.keymap`).
*   Нет необходимости писать C-код для изменения раскладки.

### 4. Расширенные возможности ввода (Behaviors)
ZMK поддерживает множество сложных поведений клавиш:
*   **Combos (Аккорды):** Нажатие нескольких клавиш одновременно для вызова символа или действия. В вашей конфигурации это используется **очень активно** (см. `chords.dtsi`).
*   **Hold-Tap:** Одно действие при кратком нажатии, другое при удержании (например, Shift при удержании, пробел при нажатии).
*   **Sticky Keys (Липкие клавиши):** Клавиша-модификатор, которая остается активной до нажатия следующей клавиши (используется у вас для `&sk`).
*   **Macro:** Запись и воспроизведение последовательностей нажатий.
*   **Tap Dance:** Разные действия при 1, 2 или 3 нажатиях одной клавиши.

### 5. Поддержка оборудования
*   **Раздельные клавиатуры:** Врожденная поддержка сплит-клавиатур.
*   **Дисплеи и энкодеры:** Поддержка OLED/e-ink дисплеев и вращающихся ручек (Rotary Encoders).
*   **Подсветка:** RGB Underglow и Backlight.

### 6. ZMK Studio (В разработке)
*   Позволяет менять раскладку "на лету" без перепрошивки (пока требует специальной ветки прошивки).

## Особенности вашей конфигурации (PNCATEHO)

В вашем репозитории используются продвинутые функции:
*   **Аккордовый ввод (Chorded Input):** Реализован через `chords.dtsi`. Вы используете сложную систему макросов `TCOMBO` для определения ввода на основе комбинаций клавиш, а не стандартной матрицы.
*   **Sticky Mods:** Используются "липкие" модификаторы (`&sk`) с быстрым сбросом.
*   **Оптимизация под Taipo:** Настройки комбо (`CONFIG_ZMK_COMBO_MAX_COMBOS_PER_KEY=128`) увеличены для поддержки сложной аккордовой системы.
